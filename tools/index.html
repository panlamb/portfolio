  • 01

    AI_to_AE_PrepIllustratorNew release · v3.5

    Storyboard arrives with everything on one layer? Drag the moon in After Effects and the whole poster moves. One click gives every object its own named layer, in the original order, one clean file per artboard. Ready to animate.

    v3.5 · Illustrator · tested on Windows, ExtendScript also runs on macOS
    What's new in v3.5 (since v3.0)
    • Big storyboards, no freezing: split with Illustrator's "Save each artboard to a separate file", open an artboard, run it "in the same file". It saves over that file and keeps a backup.
    • Choose which layers to split. The rest stay whole, one layer each.
    • A whole folder in one run, into a single "AE" folder.
    • Progress window with artboard, step and time.
